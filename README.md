# 🚀 DevOps First Mini-Project: Базовая контейнеризация и гибридный CI/CD

Мой самый первый практический проект в роли DevOps-инженера. Цель проекта — научиться базовой контейнеризации трехкомпонентного приложения (фронтенд, бэкенд, база данных) и построить гибридный конвейер автоматизации с использованием облачных и локальных мощностей.

---

## 🏗️ Архитектура приложения (Стек)

Приложение полностью изолировано и запускается в связке с помощью единого файла `docker-compose.yml`:

1. **Frontend (Nginx):** Статический веб-сервер, который отдает пользователю интерфейс (`index.html` и `script.js`).
2. **Backend (Node.js / Express):** Серверный API-код, который обрабатывает бизнес-логику и отвечает за связь с базой данных.
3. **Database (PostgreSQL):** Официальный образ СУБД для надежного хранения данных проекта.

---

## 🔄 Гибридный CI/CD Конвейер (`.github/workflows/ci.yml`)

В этом проекте была успешно реализована схема распределения обязанностей между облаком и локальной машиной:

### ☁️ ЭТАП 1: Тестирование в Облаке (GitHub-Hosted Runners)
* При каждом пуше кода в репозиторий автоматически запускаются стандартные облачные серверы GitHub.
* Они берут на себя "грязную" и изолированную работу: проверяют синтаксис, тестируют код бэкенда и фронтенда в чистой среде, не нагружая личные компьютеры.

### 💻 ЭТАП 2: Локальный Деплой (Self-Hosted MacBook Runner)
* Как только облачные тесты становятся "зелеными", управление передается локальному ранеру, развернутому прямо на моем **MacBook**.
* Локальный ранер подхватывает проверенный код, плавно тушит старые контейнеры и запускает обновленный Production-сайт в Docker на локальной машине.

## 🎯 Чему я научился в этом проекте:
* Писать кастомные `Dockerfile` для сборки легковесных NodeJS и Nginx образов.
* Связывать контейнеры в общую изолированную сеть и управлять ими через `docker-compose`.
* Настраивать и регистрировать `Self-Hosted` ранеры внутри операционной системы macOS.
* Писать синтаксис пайплайнов GitHub Actions (`YAML`) с логическим разделением шагов на тестирование и деплой.
